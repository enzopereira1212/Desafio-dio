# Prompt
"Quero que a IA gere um plano semanal de refeições saudáveis e fáceis para pessoas que trabalham fora o dia todo, com o objetivo de economizar tempo e manter uma alimentação equilibrada. Considere o seguinte contexto: rotina corrida de segunda a sexta-feira, com preparo de marmitas no final de semana. O conteúdo deve ter formato de tabela simplificada dividida por dias e refeições. Evite ingredientes caros, receitas muito demoradas e termos culinários complexos."
